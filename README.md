# 送报少年 · 雪松巷的清晨

一个纯浏览器 3D 送报游戏——灵感与玩法复刻自 [PaperRoute](https://paperroute.lol)（Paperboy 式投递游戏）。
整个世界**全部由代码程序化生成**（低多边形 + 顶点色），不依赖任何模型、贴图、音频文件，离线可玩。

## 怎么运行

方式一（macOS，最简单）：双击 `开始游戏.command`，会自动启动本地服务器并打开浏览器。

方式二（任意系统）：

```bash
cd paper-route
python3 -m http.server 8137
# 浏览器打开 http://localhost:8137/
```

> 必须通过 http:// 访问（ES Module 限制），直接双击 index.html 无法运行。
> 开发调试时可用 `python3 server.py`（禁用缓存，改完代码刷新即生效）。
> 想让局域网/全网的朋友也能玩？见 [部署指南.md](部署指南.md)。

## 玩法

骑上自行车沿街送报，把报纸投进**竖着红旗的信箱**（订户）：

- 妥投 +100，连续妥投倍率最高 **×5**
- 漏投一次订户就退订；砸了订户的窗户也会退订
- 砸非订户的窗户是恶作剧 +150（X 猛投）
- 狗在 30 米外发现你就会追——甩一份报纸引开它
- 汽车、坑洞（斑马线处还有过马路的小孩）都会让你摔车，摔一次掉一颗心
- **一周七天**难度递增（周五晚高峰、周日雨天路滑），每天按表现评级 S / A / B / C
- 完美清晨 +2500 分并吸引新订户；订户全流失或生命耗尽则一周结束
- 周日完成后进入**滑板公园**加时赛：冲坡起跳、空中收集星星、高难落地奖励
- 每周总分自动记入本地排行榜（localStorage，前 10 名）

## 操作

| 键盘 / 鼠标 | 动作 |
| --- | --- |
| ← → 或 A D | 转向 |
| ↑ / ↓（W / S） | 蹬车冲刺 / 刹车 |
| 空格 / 鼠标左键 | 投掷（虚线弧预览落点，信箱亮起时出手） |
| X / 鼠标右键 | 猛投（砸窗、引开狗） |
| 鼠标移动 | 瞄准（靠近信箱自动吸附，瞄向院子可自由瞄准） |
| Esc | 暂停 · M 静音 |

触屏：左半屏左右滑动转向 · 右下按钮 投 / 砸 / 蹬 / 刹 · 右上 ⏸ 暂停。

## 技术说明

- **Three.js r170**（已下载到 `lib/`，无需联网），纯静态页面，无构建步骤
- 所有模型（房屋 / 树 / 信箱 / 汽车 / 狗 / 骑手 / 滑板场）在 `js/assets.js` 用代码拼装，
  静态部件合并为单几何体 + 顶点色；信箱、树、栅栏等跨日共享几何体，重建街道时按
  `userData.shared` 标记跳过销毁
- 投掷为**确定性弹道**：给定起点与目标精确解算初速度（原作同款做法），而非真实物理
- 音效与背景音乐全部由 Web Audio API 实时合成（`js/audio.js`，共享噪声缓冲）
- 街道每日按种子重建（`mulberry32`），同一周内布局完全一致
- AI（狗 / 汽车 / 行人）均为带 `dispose()` 的类，日切换时完整释放几何体
- 性能：桌面满帧 60 FPS、零卡顿帧；游戏主线程每帧约 1.6ms（预算的 10%）；
  像素比 4 + 阴影 4096 的压力探针下仍满帧（GPU 余量大）

## 代码结构

```
paper-route/
├── index.html          入口页面（含全部 UI 屏幕 + 启动加载页）
├── css/style.css       报纸风 UI 样式与动效
├── lib/                Three.js 本地副本
├── js/
│   ├── config.js       全局配置 / 七天路线 / 配色 / 确定性随机
│   ├── assets.js       程序化资产库（几何体拼装 + 共享缓存）
│   ├── world.js        世界生成（街道 / 天空 / 滑板场）与生命周期
│   ├── weather.js      天气（晴 / 黄昏 / 雨）
│   ├── player.js       骑手与自行车（控制 / 摔车 / 跳跃）
│   ├── papers.js       报纸弹道 / 命中判定 / 预览
│   ├── ai.js           狗 / 汽车 / 行人（带 dispose）
│   ├── effects.js      粒子特效池
│   ├── input.js        键盘 / 鼠标 / 触控
│   ├── audio.js        Web Audio 合成音效与音乐
│   ├── save.js         排行榜存档（含输入清洗）
│   ├── ui.js           HUD / 雷达 / 屏幕 / 动效
│   ├── game.js         状态机与总控
│   └── main.js         引导与主循环（固定步长模拟）
├── server.py           开发服务器（禁用缓存）
├── 审计截图/            前后对比截图
└── 开始游戏.command     macOS 双击启动
```
