送报少年

雪松巷的七个清晨 · 骑上自行车，把报纸投进每一个竖起旗子的信箱

纯代码程序化生成的低多边形世界 · 灵感来自 PaperRoute

玩法说明

目标

把报纸投进竖着红旗的信箱（订户）。漏投一次订户就退订；砸了订户的窗户也会退订。没插旗的信箱不用理。

操作（键盘 / 鼠标）

← → 或 A D 转向 · ↑ 冲刺 · ↓ 刹车
空格 / 左键 投掷（信箱亮起时出手）· X / 右键 猛投（砸窗、引开狗）
鼠标指向信箱可精确瞄准 · Esc 暂停 · M 静音

操作（触屏）

左半屏左右滑动转向 · 右下按钮：投 / 砸 / 蹬 / 刹

小贴士

· 连续妥投，倍率最高 ×5；完美清晨 +2500 还会吸引新订户
· 狗在 30 米外就会追上来——被追就甩一份报纸引开它
· 汽车和坑洞会让你摔车，摔一次掉一颗心
· 雨天路滑，转向变钝、刹车变长
· 一周七天难度递增，每天按表现评级 S / A / B / C
